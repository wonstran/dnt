## Remaining comment

1. **[P2] Recognize `interp` in named DataFrame input to `to_work`.** The helper explicitly accepts named tables (plan lines 1650–1655), but it checks only `r3` for filled rows (lines 1656–1661). A DataFrame with the plan's own output columns (`frame, track, x, y, w, h, score, cls, interp, r4`) has no `r3`, so `to_work` inserts `r3 = -1`, keeps rows with `interp = 1`, and reports zero filled rows removed. Those old fills then become observations, contrary to design §2.5. Use `interp` as the flag when a named table lacks `r3` (or normalize the two names first), and test `to_work` with a named `interp` column containing an observed and a filled row. The new CSV validation tests do not exercise this path.
