    Post-track refinement evaluation: Raw → P1 → P2 → P3¶

    Evaluation of the post-track refinement phases on three intersection clips (beginning, middle, evening of the day):

    Phase Method
    Raw Unrefined tracker output
    P1 Motion-only (Kalman kinematic filter)
    P2 P1 plus DINOv2 appearance metric
    P3 P2 plus VLM verification (qwen3vl-32b on cutrxps)

    1. Results¶

    Unique track IDs (lower means more consolidated)¶

    Clip Raw P1 P2 P3
    beginning 63 59 59 56
    middle 89 81 81 74
    evening 134 129 131 128

    P2 evening is higher than P1 because 2 confirmed true ID switches were auto-split, which adds IDs.

    Median track duration¶

    Clip Raw P1 P2 P3
    beginning 2.5 s (25 f) 12.8 s 12.8 s 13.9 s (+456% vs raw)
    middle 5.3 s (53 f) 10.0 s 10.0 s 10.9 s (+106% vs raw)
    evening 9.6 s (96 f) 18.2 s 18.2 s 18.3 s (+90% vs raw)

    Short fragments (< 15 frames)¶

    Clip Raw P1 P2 P3
    beginning 28 12 12 12 (−57%)
    middle 23 11 10 10 (−56%)
    evening 27 10 10 10 (−63%)

    Applied links and reclassifications (P3)¶

    Raw, P1 and P2 applied no links and made no reclassifications.

    Clip Links applied of which VLM_ACCEPT Auto-applied VLM_REJECT Reclassified
    beginning 3 2 1 0 1 scooter
    middle 7 3 4 0 3 cyclists
    evening 3 0 3 3 3 cyclists, 1 scooter

    "Auto-applied" links are the ones whose combined motion and appearance confidence cleared the automatic threshold, without a VLM call. "Links applied" is the total of VLM_ACCEPT and auto-applied links. In P3 the evening clip has 3 auto links and 3 VLM_REJECT decisions.

    2. Findings¶

    2.1 P2 appearance collapses false ID-switch hypotheses by more than 90%¶

    P1 uses motion only, so it cannot tell a tracker identity swap from a real person changing velocity (turning a corner, stepping off a curb, pausing). It raised a large number of switch/SPLIT/HUMAN_PENDING candidates and could safely apply none of them:

    Clip P1 pending P2 pending
    beginning 42 2
    middle 85 5
    evening 209 18 (plus 2 true switches auto-split)

    DINOv2 embeddings show that the appearance before and after the velocity change belongs to the same individual, which filters out the false alarms.

    2.2 P3 VLM verification resolves occlusion-bridging links that math alone cannot settle¶

    When a pedestrian goes behind a bus shelter, parked SUV or utility pole for several seconds, the track splits into two fragments. The temporal and spatial gap keeps P1 and P2 confidence in the uncertain band: across the three clips, 18 links stayed in link/LINK/HUMAN_PENDING after P2, and none could be merged.

    P3 builds multi-crop evidence images (the person before the occlusion, the spatial context of the gap, the person after re-emergence) and asks the VLM:

    • middle: 3 VLM_ACCEPT merges. Together with 4 auto-applied links, unique IDs fall from 81 to 74.
    • beginning: 2 VLM_ACCEPT merges. Together with 1 auto-applied link, unique IDs fall from 59 to 56.
    • evening: 3 ambiguous candidates were all VLM_REJECT, which prevented false merges between different pedestrians on the same sidewalk corridor. The 3 applied links were auto-applied.

    2.3 Cyclists and scooters are resolved automatically¶

    Detectors often label front-on cyclists and e-scooter riders as pedestrians (cls=0). In P1 and P2, 28 reclassification events stayed unresolved in screen/RECLASS/HUMAN_PENDING because motion heuristics have no semantic context. In P3 the VLM resolves them:

    • middle: 3 pedestrians → class 1 (cyclist).
    • evening: 3 pedestrians → class 1 (cyclist), 1 pedestrian → class 36 (scooter).
    • beginning: 1 pedestrian → class 36 (scooter), plus 3 VLM_REJECT that keep true pedestrians carrying bikes or strollers.

    2.4 The disk cache makes reruns free¶

    The first run of middle_120000.00 issued 10 live VLM requests. The rerun of the same clip through the batch path reported vlm_calls: 0, vlm_hits: 10. The cache in ~/.cache/dnt/vlm is keyed on the image payload, the prompt and the model options, so an unchanged rerun makes no API requests and costs no tokens.

    3. Recommendations¶

    1. Make P3 the default production refinement tier. It resolves the edge cases where motion and appearance stall.
    2. Review the remaining edge cases by hand. Events the VLM was not at least 70% confident about stay on the static dashboards (for example middle_120000.00_ped_track_refined_p3.review.html). Only 1–2 events per clip need human sign-off.
    3. Extend to vehicles. The same P3 evidence builder and link verification can resolve vehicle occlusion switches, such as the #12 → #81 left-turn case.
